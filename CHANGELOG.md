# Changelog

All notable changes to the Astra Prompt Lab project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-14

### Added
- Initial project scaffold
- Repository structure:
  - `cases/` directories (win, fail, mixed)
  - `sources/` directories (folk, x, spider, openai placeholder)
  - `schema/` with JSON Schema definition
  - `examples/` with sample cases
- Core documentation:
  - README.md with mission, differentiation strategy, and structure overview
  - CONTRIBUTING.md with detailed contribution guidelines
  - LICENSE (MIT)
- JSON Schema for case format (`schema/case.schema.json`)
- Three example cases demonstrating schema usage:
  - Example successful case (win)
  - Example failed case (fail)
  - Example mixed case (optional)
- Clear differentiation from TripoGrowthLab/awesome-astra-prompts
- Attribution guidelines and ethical contribution rules

### Philosophy
This lab embraces both successes and failures as learning opportunities, differentiating from curated-only lists by providing real-world field data.
